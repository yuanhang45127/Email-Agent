# 每日摘要 · 收件箱盘点 + 待办（无头 LLM 任务）

你在 MailRadar 仓库根目录工作（cwd 已是仓库根）。今天是运行日，用 `date +%F` 获取日期。
本任务完全无头运行：遇到歧义按字面规则执行。

## 目标
盘点收件箱与联系人表，产出一份简短的每日摘要并推送。只读 + 通知，不改联系人表、不代发邮件。

## 步骤
1. 用 `python3 -m mailradar scan-box` 读草稿箱现状（JSON）。
2. 读联系人表（config.yaml 里 `contacts.sources` 指向的 CSV），统计：
   - 已发送未回复的条目（sent=是 且 replied≠是），按等待天数排序；
   - 草稿箱里待发送的条目。
3. 生成摘要（≤15 行）：待跟进 Top N、等待最久的几条、草稿箱待发送数。
4. 用 `radar/notify.sh "每日摘要" "<内容>"` 推送。

## 红线
- 只读联系人表与邮箱；绝不修改 CSV、绝不代发邮件或消息。
- 摘要里的每个数字都来自上一步的真实统计，不估算、不虚构。
